HOTFIX179 / Phase 4P.9CG — JBIG2 PDF Thumbnail Decode Support and Malformed-PDF Fallback Parity

Summary
- Adds JBIG2 PDF decode support via Apache PDFBox jbig2-imageio.
- Avoids the noisy thumbnails4j PDF logger path by rendering PDFs directly with PDFBox inside AsyncThumbnailService.
- Collapses malformed/truncated PDF failures into a one-shot JUL warning and normal icon fallback.

Touched files
- pom.xml
- config/logging.properties
- config/jul-loggers.txt
- src/main/java/com/fileexplorer/service/icon/AsyncThumbnailService.java

Implementation notes
1. PDF thumbnails no longer instantiate thumbnails4j's PDFThumbnailer. Word/Excel/PowerPoint document thumbnails still continue through thumbnails4j.
2. PDF thumbnails are rendered from page 0 using PDFBox Loader + PDFRenderer, then scaled through the existing square-fit helper.
3. Preflight detection remains best-effort only. If a PDF advertises JPX/JBIG2 streams and the matching reader is unavailable, the service returns null early and the UI falls back to the file-type icon.
4. Malformed/truncated PDFs are logged once per path and do not spam repeated SEVERE stack traces.
