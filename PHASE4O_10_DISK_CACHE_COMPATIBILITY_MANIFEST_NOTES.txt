PHASE 4O.10 / HOTFIX82 — Disk Cache Compatibility Manifest

Summary
- Added a lightweight manifest file in the thumbnail disk-cache root.
- Added a compatibility fingerprint for the persisted thumbnail pipeline.
- Added optional startup clearing on manifest mismatch to prevent stale on-disk thumbnails from surviving pipeline changes.
- Added manifest contents to thumbnail diagnostics and support bundle zips.

New tuning switches
- -Dfileexplorer.thumb.diskCache.manifest.enabled=true|false
- -Dfileexplorer.thumb.diskCache.clearOnManifestMismatch=true|false

Behavior
- When disk cache is enabled, the service writes thumbcache-manifest.properties into the cache root.
- The manifest captures the current compatibility fingerprint and major cache-affecting settings.
- On startup, if the saved manifest fingerprint differs from the current fingerprint and clearOnManifestMismatch is enabled, the persistent disk cache is cleared before pruning continues.
- Diagnostics now include both a summary string and the manifest contents.
