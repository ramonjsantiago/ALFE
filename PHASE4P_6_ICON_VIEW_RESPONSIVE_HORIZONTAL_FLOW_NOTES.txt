HOTFIX90 / Phase 4P.6 adjusts icon-mode horizontal flow so Extra large icons, Large icons, Medium icons, and Small icons use the full visible width of their container instead of getting stuck at an undersized fixed row count.

Changes:
- made icon viewport width changes trigger a debounced responsive layout refresh
- rebuilt virtualized icon-grid rows when the computed items-per-row changes
- aligned virtual grid row padding/gaps with the active icon mode instead of using one hard-coded row spacing
- updated items-per-row calculation to use the active mode's real tile width, hgap, and padding

Result:
- icon-mode rows expand and contract with the visible container width
- large folders using the virtual icon grid no longer stay pinned to an old three-column layout after wider space becomes available
