Phase 4H - Tabs + Home behavior (HOTFIX23)

Implemented in this package:
- Explorer-style top tab strip with Home tab, current-folder tab, and a new-tab button.
- Home surface in the main content stack with Quick access and Recent folders.
- Recent-folder tracking driven by successful folder navigations.
- Home mode hides the normal details/icon surface and collapses the right side pane.
- Ctrl+T opens the current folder in a new window as a temporary new-tab fallback.
- New CSS layer: src/main/resources/com/fileexplorer/ui/css/home-tabs-parity.css

Key touched files:
- src/main/resources/com/fileexplorer/ui/layout/MainLayout.fxml
- src/main/java/com/fileexplorer/controller/MainController.java
- src/main/java/com/fileexplorer/app/MainApp.java
- src/main/resources/com/fileexplorer/ui/css/home-tabs-parity.css

Notes:
- This phase is intentionally conservative: the tab strip is visual and interaction-oriented, while true multi-tab state is deferred.
- The "+" button currently opens a new window using the current folder, matching the Ctrl+T fallback.
