HOTFIX174 / Phase 4P.9CB — Predictive Thumbnail Decode Budgeting, Cell Reuse Sanitization, and Scroll-Jank Telemetry Parity

Summary
- Added viewport-motion aware decode budgeting for thumbnail and icon pipelines so visible work stays ahead of speculative/background work while the viewport is still moving.
- Hardened Details-view cell reuse so stale icon/thumbnail completions cannot repaint recycled cells after rebinding.
- Added lightweight scroll hitch telemetry and idle-burst logging hooks to make remaining scroll jank measurable during tuning passes.

Implementation details
- AsyncThumbnailService
  - Added viewport motion / idle tracking.
  - Added moving-background deferral so background thumbnail starts yield to visible backlog during active scroll.
  - Added queue-trim, stale-generation, and stale-subscriber counters to diagnostics output.
- AsyncIconService
  - Added viewport motion / idle tracking, moving-prefetch/background delay, visible-backlog backpressure, and queue/reject metrics.
- TableViewSupport / VisibleThumbnailManager
  - Added per-binding stamps and explicit unregister behavior for reused/emptied cells.
  - Thumbnail application now verifies the current bound path before swapping visuals.
- MainController
  - Scroll motion now notifies icon/thumbnail services directly.
  - Added optional hitch logging and idle-burst telemetry via system properties.

Suggested diagnostics flags
- -Dfileexplorer.scroll.telemetry=true
- -Dfileexplorer.debug.icons=true
- -Dfileexplorer.debug.thumbs=true

Acceptance intent
- No wrong-image flashes in Details view during fast scroll / recycle.
- Background thumbnail work backs off while visible work is still queued.
- Scroll hitch diagnostics provide concrete timing data for next-phase tuning.
