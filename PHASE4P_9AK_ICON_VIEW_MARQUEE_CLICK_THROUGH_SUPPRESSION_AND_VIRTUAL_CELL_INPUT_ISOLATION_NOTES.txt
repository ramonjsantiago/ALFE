HOTFIX131 / Phase 4P.9AK — Icon View Marquee Click-Through Suppression and Virtual Cell Input Isolation

What changed
- Added a view-host primary-click suppression pass so the click generated after a marquee drag cannot fall through and collapse the committed multi-selection to the last icon under the pointer.
- Extended marquee gesture suppression across additional JavaFX UI pulses so trailing release/click sequencing is still blocked while the committed marquee result stabilizes.
- Installed virtual icon ListCell mouse-event suppression during marquee ownership to stop the virtualization container from reasserting single-item selection on release.
- Reduced drag flicker by skipping redundant live marquee repaint passes when the hit-set has not actually changed.
