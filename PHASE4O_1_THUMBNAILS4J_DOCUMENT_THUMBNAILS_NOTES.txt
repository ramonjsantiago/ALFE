HOTFIX72 / Phase 4O.1 — thumbnails4j Lazy Office/PDF Thumbnails

What changed
- Added the Elastic thumbnails4j library to the Maven build using the 1.2.0 release line.
- Extended thumbnail candidate detection to include: .doc, .docx, .pdf, .pptx, .xls, and .xlsx.
- Routed those document types through the existing AsyncThumbnailService so they use the same lazy, gated, debounced, priority-aware thumbnail pipeline already used for image thumbnails.
- Preserved the existing placeholder-first behavior: file-type icons render immediately, then upgrade asynchronously to a generated thumbnail when ready.
- Added a runtime SLF4J NOP binding so thumbnails4j does not emit missing-binder warnings during thumbnail generation.
