HOTFIX112 / Phase 4P.9R — Structured Command Bar Chevron Render Finalization

Scope
- Replace the New / Sort / View command-bar MenuButton presentation with a fully structured graphic content tree.
- Stop relying on the native MenuButton arrow lane for visible chevron rendering.
- Keep one full-button hit target while making the down chevron always visible.

Implementation
- MainController now converts New / Sort / View into graphic-only MenuButtons with a structured HBox content payload.
- The structured payload contains a leading icon slot, a text label slot, and a dedicated trailing chevron slot.
- The visible chevron is now an SVGPath instead of the hidden/default MenuButton arrow glyph path.
- Original FXML graphics are cloned when possible so the leading icons remain intact.
- The default MenuButton arrow lane remains collapsed via the existing structured-menu-button CSS rules.
