HOTFIX130 / Phase 4P.9AJ — Icon View Marquee Gesture Ownership, Release Collapse Suppression, and Stable Multi-Select Commit

What changed
- Stopped icon-view marquee live preview from clearing and rebuilding the shared TableView selection model on every drag pulse. During drag, icon marquee now updates only the icon presentation selection set.
- Added marquee gesture ownership guards around icon-tile primary handlers so trailing primary click/clicked processing cannot collapse a completed marquee multi-selection back to one lead item.
- Held marquee gesture ownership across release-time commit and deferred guard release until later UI pulses so the committed icon multi-selection survives release/click sequencing.
- Suppressed icon hover class activation while marquee ownership is active to reduce hover-driven paint churn and visible drag flicker.
