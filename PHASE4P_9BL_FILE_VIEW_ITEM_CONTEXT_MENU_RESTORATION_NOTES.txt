HOTFIX158 / Phase 4P.9BL — File View Item Context Menu Restoration

Scope
- Restore the shared file-operations context menu for file items in non-Details file views.
- Preserve Explorer-style selection semantics on right-click.
- Keep the existing Details row context menu behavior unchanged.

Implementation
- Added secondary-button selection preparation in icon-tile gesture wiring so right-click on an unselected item makes it the active single selection before the menu opens.
- Added context-menu request handling directly to icon/list/tile/content item nodes so the same file-operations menu used by Details view now opens from the clicked file item.
- Updated shared menu anchoring to bind the context menu to whichever file-view surface is currently visible: Details table, virtual grid, virtual list, icon flow, icon scroll, or the view host fallback.

Expected result
- Right-click on a file or folder item in Extra large icons, Large icons, Medium icons, Small icons, List, Tiles, and Content opens the item context menu again.
- Right-click on an already-selected multi-selection keeps that selection intact.
- Right-click on an unselected item promotes only that item to the active selection before the menu appears.
