HOTFIX121 / Phase 4P.9AA — Details View Marquee Drag Activation Fix

Scope
- Fix details-view marquee selection so drag selection can start from existing rows, not only from empty viewport space.
- Keep normal row click behavior intact when the pointer does not cross the marquee drag threshold.
- Exclude the details header and scrollbars from marquee activation.

Implementation
- Added explicit tracking for whether marquee press began on an existing item.
- Changed details marquee arming to allow row-origin presses while still rejecting header/scrollbar targets.
- Updated drag and release handling so blank-space clicks still clear selection, but row clicks keep native single-selection behavior unless a real marquee drag starts.
