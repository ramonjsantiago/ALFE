HOTFIX115 / Phase 4P.9U — Command Bar Icon Size More Parity

Summary
- Increased the visible size of the structured command-bar vector icons used by New, Sort, and View.
- Widened the icon lane slightly so the larger icons remain centered and do not crowd the label.
- Increased vector stroke weight modestly so the icons read more like Windows File Explorer at normal desktop scale.

Changed Files
- src/main/java/com/fileexplorer/controller/MainController.java
- src/main/resources/com/fileexplorer/ui/css/explorer-override-everything.css

Implementation Notes
- Raised the structured command-bar vector icon root from 16x16 to 18x18.
- Applied a small scale-up to the SVG stroke paths so the existing New, Sort, and View shapes render larger without changing the chevron or flyout behavior.
- Increased the command-bar icon slot width from 16px to 20px and the fallback glyph size from 15px to 17px.
- Increased vector stroke width from 1.35 to 1.5 for better legibility.

Expected Result
- New, Sort, and View keep the HOTFIX113 structure: icon + label + trailing chevron.
- Their leading icons should now read larger and closer to Windows Explorer command-bar proportions.
