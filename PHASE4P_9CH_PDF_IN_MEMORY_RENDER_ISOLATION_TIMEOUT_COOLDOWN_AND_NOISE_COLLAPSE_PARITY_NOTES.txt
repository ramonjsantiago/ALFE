HOTFIX180 / Phase 4P.9CH — PDF In-Memory Render Isolation, Timeout Cooldown, and Noise-Collapse Parity

Summary
- Switched PDF thumbnail rendering from Loader.loadPDF(File) to Loader.loadPDF(byte[]) for file-channel isolation.
- Changed PDF document thumbnail timeout cleanup to avoid cancel(true) interrupt noise on active PDFBox render tasks.
- Added per-path timeout cooldown and one-shot JUL warnings for timeout / oversize / interrupt fallback cases.
- Forced noisy internal PDFBox JUL loggers OFF and kept concise service-owned fallback diagnostics.

Primary touched files
- src/main/java/com/fileexplorer/service/icon/AsyncThumbnailService.java
- config/logging.properties
- config/jul-loggers.txt
- docs/README_HOTFIX180.md

Operational note
- Large PDFs above the in-memory ceiling now skip thumbnail rendering and use the file-type icon unless the ceiling is increased via system property.
