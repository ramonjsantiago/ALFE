HOTFIX122 / Phase 4P.9AB — Details Marquee Release Selection Commit Fix

Scope
- Preserve the full marquee-hit selection in Details view after mouse release.
- Re-apply the committed marquee selection after JavaFX release processing so native row selection does not collapse the result back to a single row.

Acceptance intent
- While dragging a marquee in Details view, all intersected rows enter the selected state.
- After releasing the mouse, the same full set remains selected logically and visually.
- Ctrl-drag additive marquee selection still preserves the existing selection base.
