PHASE 4O.11 / HOTFIX83 — Disk Cache Metadata Protection and Temp Hygiene

Summary
- Protected the thumbnail disk-cache manifest from normal age/size pruning.
- Added cleanup for stale temporary cache files left behind by interrupted writes.
- Added empty directory cleanup for hashed disk-cache subdirectories after payload deletes.
- Extended diagnostics so payload file counts are separated from temporary file counts.

New tuning switches
- -Dfileexplorer.thumb.diskCache.tmpMaxAgeHours=<hours>

Behavior
- `pruneDiskCache()` now treats `thumbcache-manifest.properties` as metadata and excludes it from normal payload eviction logic.
- Only persisted thumbnail payload PNGs participate in age-based pruning and size-budget pruning.
- Stale `.tmp` files older than the configured age are deleted during prune passes.
- Empty hashed cache directories are removed after payload/temp cleanup so the on-disk cache stays tidy over time.
